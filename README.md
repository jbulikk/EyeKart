# EyeKart

A gimbal system that mimics the user's head movements in real time.
The project is divided into two cooperating parts: a transmitting unit and a receiving unit.

- The transmitting module uses an IMU sensor to capture the user's head orientation.

- The motion data is processed and wirelessly transmitted to the receiving module.

- The receiving module interprets the incoming data and controls servo motors to adjust the mechanical gimbal accordingly, replicating the user's head movement.
